# Zentro

A desktop SQL IDE where safety is the product's spine: every query runs through environment-aware guards before it reaches a database.

## Language

### Environments

**Environment**:
One of three stages a connection belongs to within a project — Development (`dev`), Staging (`sta`), Production (`pro`) — ordered from least to most critical. The older Local (`loc`) and Testing (`tes`) keys are read as `dev`.
_Avoid_: stage, tier, workspace

**Production**:
The environment with key `pro`. An identity, not a level — production-only ceremonies apply regardless of Safety Level.
_Avoid_: prod-like, live

**Active Environment**:
The environment currently selected on the Toolbar's environment switcher. It is the execution target for Query tabs and the single meaning of the Toolbar's connection display — it never changes based on which tab is focused.
_Avoid_: current environment, global environment

**Pinned Environment**:
The environment (and connection) a Table or Catalog tab is bound to at the moment it's opened, fixed for that tab's lifetime regardless of later changes to the Active Environment. Surfaced locally on the tab itself, never through the Toolbar.
_Avoid_: tab context, locked environment

### Safety policy

**Safety Level**:
The per-environment strictness policy: `strict`, `balanced`, or `relaxed`. The single axis that decides write-safety ceremony and execution limits for an environment.
_Avoid_: environment strictness, policy profile, safety environment, strong-confirm threshold

**Safety Floor**:
The invariant that Production's Safety Level is always `strict` and cannot be lowered. Only Production is floored; Staging defaults to `strict` but may be lowered deliberately.
_Avoid_: lock, hard limit

**Execution Policy**:
The resolved bundle the backend answers for an environment: Safety Level plus row cap, query timeout, and destructive rules. Resolved by the backend; the frontend only renders it.
_Avoid_: policy profile, query policy

**Strong Confirmation**:
The heavier confirm ceremony required for destructive or WHERE-less writes when the environment's Safety Level is `strict`. Derived from Safety Level — never its own setting.
_Avoid_: double confirm, strong-confirm-from-environment

**Write Safety**:
The backend guard that intercepts mutating SQL with no WHERE clause before it reaches a driver. Applies everywhere; `strict` environments escalate it from confirm to reject-without-audit-meta.
_Avoid_: write guard, safety net

**Preflight**:
The pre-execution risk assessment of a query, returning which ceremonies (unlock, type-to-confirm, cooldown, reason, snapshot) the run requires.
_Avoid_: dry run, pre-check

**Production Unlock**:
A time-boxed permission to run writes against Production, granted per environment key and expiring automatically.
_Avoid_: prod override, unlock mode

### Source Control

**Source Control**:
The project's single repository and history for user-visible change tracking. It is a capability of the project, not an optional tracking mode.
_Avoid_: git tracking, tracking repo, git module

**Source Control Automation**:
The policy layer that automatically records project artifacts into Source Control, such as script mirrors and schema snapshots. It can be enabled or disabled without removing Source Control itself.
_Avoid_: git tracking, auto git, tracking mode

**Automation Artifact**:
A file generated by the app and committed into Source Control so the project history can capture recoverable state. It belongs in a reserved artifact namespace, not alongside user-authored files by accident.
_Avoid_: internal file, tracking file, temp artifact

### Workspace

**Welcome**:
The main-area surface shown while no project is open. It offers New Project, Open Project Folder and Recent projects, and nothing that authors content.
_Avoid_: startup wizard, project gate, empty state

**Open Project Folder**:
Opening a folder that is already a Zentro project (it has a `project.json`). It never turns an arbitrary folder into a project.
_Avoid_: import folder, open workspace
