### Breaking Changes

- **Connections are now a single global pool.** Connections used to be stored inside each project. They now live in one shared pool, and each project environment points to a pool connection plus the database it's bound to. Your existing connections are folded into the pool automatically the first time you launch v0.6.0 — deduplicated by driver / host / port / database / user, with saved passwords carried over. No action needed, but a connection you set up in one project is now visible to all of them.
- Connection export/import now uses a `{ version, connections: [] }` bundle (secrets are always stripped). The old single-connection package can still be imported.

### New Features

- **Redesigned project wizard** — create and edit projects through a new profile dialog with an Environment Matrix picker for wiring each environment to a connection, a quick-switch context menu, a teal default project colour, and a responsive layout
- **Quick project switcher** — jump between projects straight from the toolbar, with full keyboard navigation
- **Theme presets and fonts** — pick a built-in preset (Zentro Light, Zentro Dark, or Solarized) and set separate font families for the UI and the SQL editor, all from Settings
- **Built-in update button** — the update check is now always on and no longer configurable (VS Code style). When a newer release is available, a compact **Update** / **Restart to Update** button appears in the toolbar; hover it to see your current version and the latest one. No more auto-popup modal.
- **Extensible bottom panel** — the editor's bottom panel is now a registry hosting Audit, Output, App Log, and Query Stats, with room for more over time
- **VS Code-style empty editor state** — a cleaner starting screen for a new query tab, with a right-sidebar resizer that stays in sync
- **Data grid zebra striping** — alternating row shading and header dividers that hold up while scrolling
- **Broad UI redesign** — unified panel borders and corner radii, resizable sidebars, a boxed settings navigation, and a refreshed tab strip and result panel; the first-run window can now be dragged by the dialog background

### Fixes & Polish

- The light/dark switch in Settings now applies on the first click, and changing the theme no longer wipes the font/preset fields on save
- Consistent panel divider across every theme; the active tab now has a surface distinct from the tab strip; Solarized presets match the canonical palette
- Edited cells now generate provider-correct SQL literals
- The result panel only auto-opens for real editor query runs, not background queries
- Log views no longer re-theme every open Monaco editor
- `time.Time` values render in a single canonical form instead of Go's doubled timezone
- Context Search: table tabs opened from the palette stay pinned to the toolbar context, and the list resets scroll and selects the first row on every new query
- Window controls stay pinned to the top-right corner, and every dialog has rounded corners
- The "no connection" notice is debounced so switching projects doesn't flash it
- Typing in the editor feels immediate again — the Monaco-to-store sync is debounced — and the result grid stays smooth under fast scrolling
