### Breaking Changes

- Pro Early Access is gone, replaced by a 30-day free trial of Pro available to everyone — no invite needed.

### New Features

- **Zentro's core is now open source** — the SQL IDE core ships under GPL-3.0-only; Pro stays a separate, licensed layer on top. See the README for what that means for building from source.
- **30-day Pro trial** — start it from Settings or any upgrade prompt; no credit card, and Upgrade to Pro now opens a real checkout session instead of just the pricing page.
- **Activity panel and background jobs** — long-running work (CSV import, full-table export) now runs as a cancelable job with live progress, instead of blocking the UI; a new Jobs tab tracks them, and a Server Sessions tab lists and can kill sessions on the database itself.
- **AI assistant, much further along** — a redesigned chat panel with saved history, streaming replies, and mention shortcuts; the assistant can now validate SQL, explain query plans, diff schemas across environments, find what breaks from a change, and read table/index stats, all gated to the schema it's allowed to see (ADR 0017) and fully free to use with your own model key, including the MCP server for external agents.
- **SSH tunnel and TLS controls per connection** — reach a database through an SSH tunnel, and set a minimum TLS version or allow legacy ciphers when a server needs them. The connection form also takes a connection string per driver (`postgres://`, `mysql://`, `sqlserver://`), with the right examples and defaults for each.
- **In-app terminal** — a local or SSH terminal lives in the bottom panel next to Activity and AI chat.
- **ERD improvements** — automatic layout (dagre), a minimap, keyboard pan/zoom, and a reset-layout control.
- **SQL editor polish** — its own SQL grammar so custom token colors always win over Monaco's defaults, schema-aware coloring of tables/columns/aliases, a redesigned Colors settings page with live preview, and a T-SQL-aware formatter.
- **Keyboard navigation overhaul** — roving-tabindex through the explorer tree and result grid, command-palette tab-jump, chord shortcuts, and Enter/F2 to start editing a cell.
- **Ctrl+Tab goes to your last tab** — it now switches to the most recently used tab, and holding Ctrl while pressing Tab walks further back, like a browser. Next/previous tab moved to Ctrl+PageDown / Ctrl+PageUp.
- **First-run product tours and a daily tip dialog** for new installs.

### Fixes & Polish

- **Security:** paid plans are now granted only from a verified signed entitlement, and the `ZENTRO_DEV_TIER` test override can no longer leak into a release build.
- AI: fixed empty/streaming replies on providers that ignore streaming, a stuck-reply timeout, and the chat model picker staying visible during setup.
- Activity: fixed an infinite re-render loop in the status-bar job indicator and incorrect export progress percentages.
- Result grid: drag-select survives missed mouse events, and copying a row selected via the index column works again.
- Shortcuts: chord completions now correctly win over single-key rules sharing a key, and Alt combos work on macOS.
- About now shows the real build commit and date on release builds.
- Sessions tab no longer lists Postgres's own background workers.
- Connection form: the SSL mode and TLS version lists open above the dialog again, and Test / Cancel / Save stay pinned at the bottom instead of scrolling away.
- The command palette closes when you click outside it, not only on Esc.
- The assistant's run-history tools now stay off until you turn on **Run history** in Settings → Assistant, as the setting says.
