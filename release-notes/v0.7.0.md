### Breaking Changes

- **An unbound project environment now errors instead of silently connecting to the pool's bootstrap database.** Previously, an environment with no database of its own fell back to the connection's `db_name`. That fallback is gone — the database a project works against lives only on the environment binding. The upgrade backfills every existing environment from its connection so nothing you already use breaks; but a *new* environment with no database picked will now report a clear "unbound" error rather than connecting somewhere unexpected.

### New Features

- **Settings → Connections** — a dedicated page that is now the single place to manage the connection pool: create, edit, test, and delete connections, list and create databases per connection, and import or export them (moved here from the project dialog). Deleting a connection tells you how many project environments across how many projects still use it.
- **Create a connection during first-run onboarding** — a fresh install with an empty pool can now add its first connection inline from the startup project wizard, instead of hitting a dead end that required restarting the app. The provider picker — choose Postgres, MySQL, SQLite, and the rest by its logo — is back on both the onboarding flow and the Settings page.
- **Stable connection identity** — every pool connection now has a permanent ID. Renaming a connection no longer orphans the project environments bound to it or the password saved in your OS keyring. This also fixes a reported bug where picking a different database in a project's environment matrix still connected to the previous one.
- **The environment matrix is now a pure binder** — it picks a connection and a database, nothing more; all connection editing routes to Settings → Connections. Rebinding the database of the environment you're currently connected to now reconnects the live session and tells you what happened, and merely opening a picker while editing a project no longer switches your connected environment when you save.
- **Live project names and colours in the connection list** — the "used by" column reads project names and identity colours from the live project store, so a project renamed elsewhere updates here immediately instead of after a restart. A new **Refresh** button reloads connections, database probes, and bindings together.
- **Per-database bindings view** — expanding a connection now shows two columns: every database (including ones a project references but the server no longer has, flagged "not on server") and the project environments bound to each.

### Fixes & Polish

- **Toolbar centre content is actually centred on the window** — an asymmetric inset that reserved the corner for the window controls was pulling the centre cluster about 69px off true centre; the chrome insets moved onto the side clusters instead.
- Internal cleanup: removed the last of the inline connection-CRUD code from the project dialog and environment matrix, and made every frontend call site resolve a project's connection reference by ID rather than by display name.
