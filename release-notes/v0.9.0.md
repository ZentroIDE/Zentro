### New Features

- **Live SQL diagnostics** — the editor now flags unknown columns and ambiguous references as errors inline (Error Lens style) as you type, with did-you-mean, qualify, and refresh quick fixes, and a Settings toggle to turn it off.
- **Smarter completion** — suggestions are now dialect-aware, qualify columns by alias in multi-table joins, offer `alias.*`/`All columns` expansions, pull in foreign-key related columns with the LEFT JOIN they need, and write long select lists comma-first, one column per line. `Expand *` and a quick Run command (Ctrl+Shift+Enter) round it out.
- **Safer deletes** — deleting or dropping rows now shows which other tables actually reference them, lets you view those referencing rows before confirming, and only warns when a real reference exists.
- **Query results, unsaved-edit aware** — re-running a query keeps a result tab's unsaved edits instead of discarding them, and F5/reload now honours the active filter and asks before dropping unsaved changes.
- **One Messages/Summary tab per run** — server messages (including MSSQL `PRINT`/`RAISERROR` output) collect into a single Messages tab, and multi-statement non-SELECT runs get one Summary tab instead of one per statement.
- **Smoother scrolling** — mouse-wheel scrolling is eased across the query editor, result grid, and tab bars.
- **PII blur is now a real guard** — blurring sensitive columns when presenting actually prevents exposure instead of only being a visual effect.
- **Native installers for Linux and macOS** — Linux ships as `.deb`, `.rpm` (Fedora), and AppImage (with zsync auto-update and bundled GTK3/WebKit2GTK) in place of the raw binary/tarball; macOS gets an ad-hoc signed `.pkg` installer with auto-update.
- **Theme system rebuilt** — Button components now use a dedicated token layer with an accent rebrand, and Solarized Light gets its own primary color instead of borrowing Dark's blue.
- **Faster project switching** — new connections can be added directly from the environment picker, and first-time Project creation is gated on a privacy notice.

### Fixes & Polish

- Explorer: working reconnect button, virtualized object list, debounced filter, and no more duplicate concurrent schema fetches or cascading query failures on reconnect.
- Result grid: correct drag-select column ranges, immediate column auto-fit on double-click, and cell editors that re-render on every keystroke.
- Theme: full token architecture overhaul (Seed → Map → Alias, `danger`/`error` renamed to `destructive`) with parity fixes across all four built-in presets, and multiple Solarized contrast/selection fixes.
- Editor: builtin SQL snippets insert as real Monaco snippets, fonts re-measure once the webfont loads so the caret lines up, and query/table tabs stop re-rendering on unrelated actions.
- SQL generation: correct N-prefixed unicode strings for SQL Server, escaped backslashes for MySQL, and Postgres dollar-quoted bodies kept as one statement.
- MSSQL: batch-scoped statements stay together and PRINT output is no longer dropped when throttled.
- Autosave no longer writes on every keystroke; table columns fetch once instead of three times.
- Toolbar shows a sweeping progress bar while connecting instead of a pulse, and stays in sync when the active connection is edited elsewhere.
- Update dialog redesigned and no longer shows the wrong current version.
- Stray console windows removed, data-grid selection UX cleaned up, and F1/keyboard-shortcut help added.
