# Security

## Reporting a vulnerability

Do not open a public issue. Report the vulnerability privately through one of:

- GitHub private vulnerability reporting (available once the repository is public).
- Email: security@zentro-ide.com.

Please include:

- the affected component and version
- steps to reproduce
- impact and any proof of concept
- a suggested fix, if you have one

## Response

First response within 7 days. This is best effort — the project has a single maintainer.

## Supported versions

- The latest release of the official build.
- The current `dev` branch of the core.

## Scope

- The core.
- The official build.
- The license system.
