## Why contributions need a CLA

The copyright holder owns the copyright in the core. That ownership is what allows the same code to be distributed in two ways: as this GPL-3.0-only source, and inside the official build, which also contains proprietary Pro features under a separate end-user agreement.

Code from other contributors is only usable in both ways if its copyright holder licenses it to the project on terms that allow it. That is what the [Contributor License Agreement](CLA.md) does. Without it, a contribution could be merged into the core but not shipped in the official build.
